# 预选方案：国内云中转与米家环境数据显示

> **状态：预选，暂缓推进。**本文是设计方案，不是已完成的实现：尚未部署本方案的云服务、完成米家设备兼容性测试或提供可烧录的云版固件。本文中的服务、额度和设备兼容性均需在实施时重新核实。

目标是在电脑保持开机并联网的条件下，让 ESP32-C6 通过自身 Wi-Fi 从国内云服务获取 Codex 额度、天气及米家设备的环境数据。开发板与电脑可以处于不同网络。原有 [Wi-Fi 版](../wifi/README.md) 与 [蓝牙版](../ble/README.md)保持独立；本目录仅记录预选方案。

## 数据路线

```text
米家净化器 / 空调 ──> 小米云 ──> Home Assistant 小米官方集成 ─┐
Codex 账号登录状态 ──> 电脑本机 Codex app-server ──────────┼─> 电脑端采集与上传
天气服务 ────────────────────────────────────────────────┘           │
                                                            HTTPS 上报
                                                                 ↓
                                                  国内云函数 + 快照数据库
                                                                 ↓
                                                     ESP32 Wi-Fi / HTTPS 读取
```

电脑端通过 Home Assistant 读取已授权且支持的米家实体，汇总有限的显示字段并上报；国内云服务只保存最新快照，开发板只读取快照。电脑联网、开机并运行相关程序是当前设计的前提：Codex 额度沿用本机已登录账号的 `codex app-server`，电脑停止运行后云端不能自行更新这一数据。

设备进入米家 App 的设备列表，与读取其他米家设备的数据是不同功能。此方案先考虑**在屏幕上显示米家数据**，不承诺让 ESP32 成为米家 App 中的受支持设备，也不默认提供家电控制。

## 米家设备与显示信息

优先通过 [小米官方 Xiaomi Home 集成](https://github.com/XiaoMi/ha_xiaomi_home/blob/main/doc/README_zh.md)进行 OAuth 授权并导入 Home Assistant。拟优先检查空气净化器的 PM2.5、温度、湿度、空气质量状态、滤芯寿命，以及空调的运行状态和设定温度。具体字段、单位、设备状态和更新频率必须以用户的实际型号及 Home Assistant 可读取实体为准；无法读取的字段显示不可用，不编造数据。

空气净化器读数反映的是传感器附近环境；不同房间需要分别具备对应传感器或设备。产品的净化能力不等于具有相应污染物的浓度传感器，不能据此推断甲醛、CO₂ 或 TVOC 数值。

小米官方说明其集成支持大部分设备，但部分设备品类不支持；云模式、本地模式及网关要求依设备和固件而异。是否需要网关、当前型号是否能读取所需字段，必须先行验证。Windows 可使用虚拟机运行 Home Assistant OS，官方指南列出的最低配置为 2 GB 内存和 2 个虚拟 CPU；实际占用和性能需要按电脑配置评估。 [Home Assistant Windows 安装指南](https://www.home-assistant.io/installation/windows/)

拟采用三页左右滑动：

1. 桌面：时间、日期及室外天气。
2. 室内环境：设备实际可提供的温度、湿度、PM2.5、净化器状态及数据更新时间。
3. Codex：五小时和每周剩余额度、重置时间。

具体版面和字段在真实设备兼容性验证之后再确定。

## 国内云服务候选

首选候选为**腾讯云 CloudBase 免费体验环境**，通过 HTTPS 云函数和数据库实现快照中转，不要求自行维护云服务器。按 2026-11-11 查阅的[腾讯云价格说明](https://cloud.tencent.com/document/product/876/75213)，免费体验环境提供每月资源点、单次 6 个月且需要手动续期；具体额度、开通条件、超限处理和收费规则以实施时官方公告和控制台为准。

CloudBase 默认免费域名仅适合开发测试，官方列有访问频率、有效期和稳定性限制；ESP32 能否稳定通过 HTTPS 访问需要实测。长期使用可能需要已备案自定义域名及相应费用。 [CloudBase HTTP 访问服务](https://cloud.tencent.com/document/product/876/122894)

如果屏幕每 30 秒读取、电脑每 60 秒上传，按 30 天连续运行估算约 12.96 万次请求。调用次数不等于资源点；函数耗时、数据库读写、存储和流量也可能消耗额度，因此不能保证长期免费。实施前需验证实际用量与超额后行为。

## 安全与可靠性要求

- 小米账号凭据、Home Assistant 令牌和 ChatGPT 登录凭据仅保存在可信的采集端，不上传仓库、云端快照或开发板；Home Assistant 本地配置及备份需妥善保护。
- 电脑上传和开发板读取使用不同凭据，开发板使用只读权限；传输使用 HTTPS，并验证服务器证书和域名。不得把现有未加密的局域网 HTTP 服务直接暴露公网。
- 云端只保存显示必需的数据。每项数据保留独立来源与更新时间；采集失败时显示过期或离线，避免将旧值误当实时值。
- 后续需设计首次配网、换网、网络中断重试、时间同步与证书校验，并在实际开发板上测试内存余量、持续运行和断线恢复。
- 不记录具体账号、家庭名称、设备标识、配对码、真实额度、Wi-Fi 密码或令牌到公开仓库。
