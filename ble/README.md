# 独立蓝牙方案

此目录是独立开发中的蓝牙版本：`dashboard/` 是独立的双页面固件，`ble_backend/` 是电脑端天气与 Codex 数据采集，`pc/` 是 Windows 蓝牙发送程序，`firmware/` 是仅用于模拟数据测试的独立探针。原项目的 `firmware/` 和 `backend/` 保持 Wi-Fi 方案。

蓝牙版的开发板不需要连接 Wi-Fi；电脑需要开启蓝牙并保持本机程序运行，且通过自身网络获取天气和 Codex 数据。电脑与开发板需要处于蓝牙通信距离内。电脑端只发送白名单显示字段；ChatGPT 凭据不会发送给开发板。PIN 配对、受认证加密的读写、模拟消息和重新连接已于 2026-10-29 在实机验证；双页面固件与真实数据的完整联调仍在进行中。
